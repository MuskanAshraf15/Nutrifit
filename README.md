# Nutrifit
NutriFit is a rule-based calorie and food recommendation web application that calculates users’ nutritional needs and provides personalized meal recommendations based on their health profile, goals, food preferences, activity level, and budget.
## Features
User registration and OTP verification
Secure login and password recovery
* BMI and BMR calculation
* Personalized daily calorie recommendations
* Breakfast, lunch, and dinner recommendations
* Food recommendations based on goals, activity level, preferences, and budget
* Meal feedback and disliked food management
* Weight progress tracking
* User profile management
* Admin dashboard for managing users, foods, feedback, and messages

Technologies Used
Frontend:React.js
Backend: Python Flask
Database:MySQL
Dataset:Kaggle Food Dataset
Authentication:JWT and OTP verification

## Recommendation Approach

NutriFit uses a **rule-based recommendation approach** rather than machine learning. Food recommendations are selected according to the user's calorie requirements, meal type, food preference, activity level, weight goal, budget, and previous feedback.

Note
NutriFit is intended for general nutritional guidance and does not provide medical diagnosis or professional medical advice.
